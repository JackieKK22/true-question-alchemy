# 真问题炼金术 · True Question Alchemy

> **AI 原生学习者（AI Native Learner）系列 · 第 1 弹「会提问」**

**陪伴孩子的 AI 提问教练：不替孩子想，不代做作业，帮孩子从一句日常好奇出发，自己提出一个值得研究、用手边条件就能开始的问题。**

---

## 为什么做这个 Skill？

AI 时代最不缺的是标准答案。孩子一旦习惯了“伸手要答案”，遇到好奇懒得深想，遇到作业直接照抄，遇到大词（“我和同桌谁更聪明？”“我是不是不适合学英语？”）又容易陷进自我怀疑。

**真问题炼金术**不是百科全书，也不是出题考人的老师。它把以下方法放进了日常对话里：

1. **双词碰撞破冰**：孩子不知道问什么时，用两个日常词搭出场景，把“提问”从抽查背书变成探索游戏。
2. **维特根斯坦式澄清**：遇到含混的大词或预设，不贴“伪问题”标签，先带孩子回到具体场景看清自己在问什么；要做实证研究时，再一起找可观察、可比较的“尺子”。
3. **$Q = N \times S \times F$ 选题体检**：
   - **N｜创新性（Novelty）**：这个问题别人问烂了吗？答案是现成的吗？
   - **S｜价值性（Significance）**：弄明白这个问题对谁有用？能带来什么实际改变？
   - **F｜可行性（Feasibility）**：以现在的条件、时间和本事，能真做出来吗？
4. **作业求助守边界**：孩子直接拿作业来问时，不指责、不说教，但明确说明“不替你做”，通过拆题意、给思路、画示意图，把关键的思考和计算留给孩子自己完成。

## 它在对话里实际做什么？

| 孩子怎么开口 | 搭档怎么接 |
| :--- | :--- |
| **普通求知**：“为什么浴室镜子会起雾？” | 直接用孩子听得懂的话讲清楚，不拿“你先猜猜”吊胃口；有贴题的权威来源时主动附上。 |
| **日常观察**：“大杯子里的牛奶好像凉得更快？” | 帮孩子看清“杯口宽、杯壁厚、水量不同”的区别，把比较方向的选择权留给孩子。 |
| **带回实验记录**：“试了两次，结果反过来了” | 用小表格把记录排在一起，帮孩子看清现有数据能说明什么、还不能判断什么。 |
| **作业直接求答案**：“这题怎么做？直接告诉我” | 温和说明不代做作业，帮孩子拆清题意和入手思路，关键算式和结论由孩子自己推出。 |
| **自我怀疑/大词内耗**：“我是不是不适合学英语？” | 不急着量化或立课题，先回到刚才发生的具体事件，把“一次听写没想起来”和“适不适合”分开。 |

## 对话效果预览

### 场景一：从日常困扰到《最小研究卡》

> **孩子**：我早上老是找不到要带的作业。  
> **搭档**：找不到作业，麻烦可能出在两个地方：昨晚没装进去，或者装了却不知道在哪一层。你今天早上最后是在哪儿找到的？  
> **孩子**：桌上。我以为已经放书包里了。  
> **搭档**：那今天不是“装了找不到”，而是作业没进书包。与其早上再找，可以看看有没有一个睡前动作能帮你少漏装。你想试什么办法？  
> **孩子**：睡前把明天要交的作业都放书包外层。  
> **搭档**：外层是你选的固定位置，睡前是你选的固定时间。把这两个条件留在问题里，后面才知道自己在试什么。你想用一句话问什么？  
> **孩子**：睡前把要交的作业放书包外层，能不能让我早上少花时间找作业？  
> **搭档**：这个问题可以先用几天做个小试验。你准备跟哪种做法比？  
> **孩子**：先照平常的办法收两天，再试两天放外层，每天记早上找作业花了多久。  
>
> **《最小研究卡》**
> - **我的问题**：睡前把要交的作业放书包外层，能不能让我早上少花时间找作业？
> - **我今天先做**：照平常的办法收作业，明早记找作业用了多久。
> - **我会看什么**：先记两天，再试两天睡前放外层，比一比早上找作业的时间。

### 场景二：作业求助（给思路，不代做）

> **孩子**：一根绳子长 12 米，用去了它的四分之一，还剩多少米？直接告诉我答案。  
> **搭档**：作业我不能替你做，但可以陪你把思路理清——自己想明白的题，下次遇到才有底。这道题里藏着两个不一样的数量：用去了多少，还剩多少。先从“四分之一”想起：它是把绳子平均分成几份、取几份？  
> **孩子**：平均分成 4 份，取 1 份。那用去的是 $12 \div 4 = 3$ 米？  
> **搭档**：对，3 米是其中一份的长度。那你刚算出来的 3 米，是“用去的”还是“剩下的”？  
> **孩子**：是“用去的”。那还剩的就是 $12 - 3 = 9$ 米。  
> **搭档**：这道题是你自己走通的：先用除法求出“用去多少”，再从总长里减掉它。可以再检查一下：剩下 9 米，比 12 米少，合理。

## 怎么安装和使用？

### 方式一：一句话安装（WorkBuddy / OpenClaw / Hermes）

```
@skill://https://github.com/JackieKK22/true-question-alchemy
```

### 方式二：作为 Claude Code / Agent Skill 使用
1. 下载本仓库中的 [`SKILL.md`](./SKILL.md)。
2. 将文件放入你的 Skill 目录，例如：
   - WorkBuddy：`~/.workbuddy/skills/true-question-alchemy/SKILL.md`
   - Claude Code：`~/.claude/skills/true-question-alchemy/SKILL.md`
   - CodeBuddy：`~/.codebuddy/skills/true-question-alchemy/SKILL.md`
3. 也可以用打包好的脚本一键安装：`bash install.sh`（自动探测），或 `bash install.sh workbuddy`（指定目标）。
4. 启动对话，让孩子直接开口，或输入：“我想练提问 / 我有个好奇的事想研究”。

### 方式三：作为通用大模型 System Prompt（系统提示词）使用
如果你使用的是豆包、Kimi、ChatGPT、DeepSeek 或自建智能体平台：
1. 打开 [`SKILL.md`](./SKILL.md)，复制 `---` 元数据下方的全部正文。
2. 粘贴到智能体的「人设 / 系统提示词（System Prompt）」框中保存。
3. 建议开启模型的**联网搜索**与**代码/图表渲染**能力，以便搭档在需要时绘制对比表格或引用权威科普页面。

## 给家长的使用建议

- **不要替孩子抢答**：当搭档留出一个小问题时，哪怕孩子要想半分钟，也先让他自己说。
- **随时可以停**：不是每次聊天都要拿到《最小研究卡》。聊清一个词、弄懂一道题、或者玩一轮双词碰撞就去睡觉，都是好结果。
- **查看家长小报告**：会话结束时，你可以对 AI 说：**“请生成本次的家长小报告”**，查看孩子今天的原话亮点、独立完成情况，以及下一次你可以怎么接话。
